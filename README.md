# MultiplayerTest

Тестовый многопользовательский проект на Unreal Engine 5: два игрока подключаются друг к другу через лобби Steam, открывают синхронизируемый сундук и подбирают предмет в личный сеточный инвентарь.

## Скачать тестовый билд

> **Windows:** [Скачать MultiplayerTest](https://drive.google.com/file/d/1J2IAcwZhWSwHj2M5kJ6gqdkXsC8hohdH/view?usp=sharing)

После загрузки распакуйте архив в отдельную папку и запустите `MultiplayerTest.exe`. Для сетевого теста нужны два компьютера, два разных аккаунта Steam и запущенный клиент Steam на каждом компьютере.

## Сценарий проверки

1. Запустить билд на двух компьютерах под разными аккаунтами Steam.
2. На первом компьютере оставить лобби публичным и нажать кнопку создания игры.
3. На втором компьютере обновить список серверов и подключиться к найденному лобби.
4. Убедиться, что оба игрока находятся на одном уровне и видят друг друга.
5. Подойти к сундуку и нажать `E`. Открытие сундука должно отобразиться у обоих игроков, после чего появится аптечка.
6. Подобрать аптечку вторым нажатием `E`. Она должна исчезнуть у обоих игроков и появиться только в инвентаре подобравшего игрока.
7. Открыть инвентарь клавишей `F`, проверить отображение предмета, перетаскивание внутри сетки и выбрасывание за её пределы.

## Управление

| Действие | Клавиша |
| --- | --- |
| Перемещение | `W`, `A`, `S`, `D` |
| Обзор | мышь |
| Прыжок | `Space` |
| Взаимодействие | `E` |
| Открыть или закрыть инвентарь | `F` |
| Закрыть инвентарь | `Esc` |
| Переместить предмет | перетаскивание ЛКМ |
| Выбросить предмет | перетащить за пределы сетки/инвентаря |

## Что реализовано

- Listen Server на двух игроков.
- Создание публичного или приватного лобби через Steam Online Subsystem.
- Поиск публичных лобби проекта и подключение через Steam без прямого IP.
- Синхронизированное открытие сундука и появление предмета.
- Серверная проверка взаимодействия и подбора.
- Личный инвентарь размером 8 × 8 клеток с owner-only репликацией.
- Перемещение и выбрасывание предметов из инвентаря.
- Главное меню, список серверов, статус сетевых операций и выход из сессии.

## Техническая информация

- Платформа: Windows 64-bit.
- Сетевой режим: Listen Server.
- Online Subsystem: Steam.
- Транспорт: Steam Net Driver / Steam P2P.
- Тестовый Steam App ID: `480`.
- Игровая карта: `/Game/Maps/L_Game`.
- Главное меню: `/Game/Maps/L_MainMenu`.

Подробное устройство проекта приведено в [ARCHITECTURE.md](ARCHITECTURE.md).

## Известные ограничения

- Проверка Steam-соединения в одном локальном экземпляре редактора не заменяет тест на двух аккаунтах Steam.
- App ID `480` является общедоступным тестовым приложением Steam. Результаты поиска дополнительно фильтруются по идентификатору 
- Проект рассчитан максимум на двух участников сессии.
